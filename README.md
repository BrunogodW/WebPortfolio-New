## 📖 Sobre o projeto

Este repositório contém o código-fonte do meu **portfólio pessoal**, onde apresento quem eu sou, minhas habilidades e meus projetos, além das formas de entrar em contato comigo.

O site é uma página única (*one-page*) com navegação por seções, desenvolvida com foco em um visual limpo, moderno e responsivo, unindo minhas áreas de interesse: **programação** e **design**.
